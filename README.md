# Atualizações do Essencial

Este repositório público distribui os instaladores Windows do navegador Essencial. O aplicativo consulta a [última versão](https://github.com/Luiziano/essencial-updates/releases/latest), baixa o instalador e confere o SHA-256 publicado pelo GitHub antes de iniciar a atualização.

O código-fonte do aplicativo permanece no repositório privado do desenvolvedor. Os instaladores são publicados por um workflow do projeto após a compilação.
